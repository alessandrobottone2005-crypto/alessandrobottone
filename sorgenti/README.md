# originali creativi

Questa cartella conserva i materiali da cui si preparano gli asset del sito. Le copie web sono in `public/` oppure nei file dei progetti in `src/content/progetti/`. `sorgenti/` è esclusa dal deploy Vercel.

| cartella | contenuto |
|---|---|
| [computer](computer/README.md) | unico computer scelto: Macintosh 128K con scrivania; originale intatto in `originali/`, derivato rigenerabile in `export/` |
| [sala](sala/README.md) | sala originale, scene Blender, luce cotta e preparazione web |
| [landing](landing/README.md) | scena Blender completa per render: sala, postazione, logo animato e interfacce reali incorporate |
| [logo](logo/README.md) | logo originale SVG e GLB |
| [logo-3d](logo-3d/README.md) | scene Blender del volto, texture, script, esportazioni e anteprime |
| [foto](foto/README.md) | foto originali e materiali dell’avatar a punti |
| [audio](audio/README.md) | fonti, licenze e originali audio locali |
| [font](font/README.md) | Outfit Black statico e licenza |
| [progetti](progetti/README.md) | originali dei progetti conservati sul disco |
| ambiente | prove della greybox precedente, conservate come storico |

I risultati dei controlli sono raccolti in `verifiche/risultati/`, separati dai materiali creativi. Il vecchio PC e il Macintosh Classic alternativo sono stati eliminati il 6 ottobre 2026 su richiesta di Alessandro. La cronologia Git mantiene le versioni precedentemente registrate.
