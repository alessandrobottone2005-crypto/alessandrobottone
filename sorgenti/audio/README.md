# audio: originali

Gli originali stanno solo sul disco (`*.mp3` e `*.wav` sono ignorati da git); nel sito ci sono le versioni leggere in `public/audio/`, rigenerabili con `npm run prepara-audio` (vedi [docs/audio.md](../../docs/audio.md)).

Dei suoni di Freesound è stata scaricata l’anteprima hq (mp3 128 kbps, la stessa licenza dell’originale): il file intero richiede l’accesso con un account. Per una qualità maggiore si può scaricare l’originale dalla pagina indicata, salvarlo qui con lo stesso nome (`freesound-<id>.mp3`, convertendo in mp3 se serve) e rilanciare lo script.
